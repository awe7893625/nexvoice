# 隱私說明

NexVoice 預設在本機處理錄音與轉錄。錄音、轉錄文字、歷史紀錄與詞彙資料留在使用者的 Mac；應用程式不要求帳號，也不會因為設定檔中存在 API key 就自動上傳資料。

只有在使用者明確開啟雲端 STT 或雲端文字整理、且未開啟零成本/隱私模式時，相關資料才會送往選定的供應商。Gateway 亦要求每次本機 API 呼叫帶有每次安裝產生的 `X-NexVoice-Token`。雲端供應商的資料保留與處理規則由其服務條款決定。

使用者可以在設定中停用雲端功能、清除歷史紀錄與移除本機憑證。公開版本不得記錄 API key、原始音訊或完整轉錄內容到 world-readable log。
